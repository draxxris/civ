# ID map

8033 unique game IDs. Full record mapping is in id-map.json.

Primary classes remove their documented type prefix. Secondary classes retain their
complete symbol.

Cross-class name conflicts add the class stem and complete source symbol. Neutral
substitutions precede lowercase conversion.
