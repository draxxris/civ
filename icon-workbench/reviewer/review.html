How approval works

New items start checked. Saving approves each checked replacement. Uncheck an item to reject it, then enter a note before you save.

Rejection notes save with the item so they can guide regeneration. Items stay unreviewed until you save. Saving does not install any icon.

All decisions save in icon-workbench/review-selections-8x8.json.

Crop note: Each candidate uses its exact 90×90 artwork region from an 8×8 sheet, resized to 64×64. Pink gutters are excluded. Frames and badges are added separately. Reject an item if its subject looks cut off, and add a note.
